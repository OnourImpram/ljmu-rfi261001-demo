# Security and responsible reporting

This repository contains a synthetic-data reference application. It requires no secrets and must not contain patient records, access tokens or production credentials. Do not put sensitive information in issues, screenshots or test fixtures.

Report a suspected vulnerability privately to **onour@onourimpram.com**, including the affected release, reproducible steps and expected versus observed behaviour. Use synthetic data in the report.

The walkthrough persona selector is not authentication. Production services require server-side enforcement, protected storage, identity integration and release assurance. See `docs/architecture.md` for the reference application’s scope.
